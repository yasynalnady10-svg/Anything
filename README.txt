كل حاجة - مشروع APK

الخطوات (من غير ما تنزل أي برامج):
1) اعمل حساب على github.com لو معندكش، واعمل Repository جديد (اسمه مثلا kol-haga).
2) ارفع كل ملفات المجلد ده جوه الـ Repository (Add file > Upload files). لازم يترفع كمان مجلد .github.
3) افتح تبويب Actions، واختار Build APK، واضغط Run workflow (او هيشتغل لوحده بعد الرفع).
4) استنى حوالي 5 دقايق. افتح التشغيلة الخضرا، ونزّل من Artifacts ملف kol-haga-apk (zip فيه app-debug.apk).
5) فك الضغط، ابعت الـ APK للموبايل وثبّته (فعّل "التثبيت من مصادر غير معروفة" لو طلب).

ملاحظات:
- النسخة دي بتفتح روابط البحث (خرائط، فيسبوك، إنستجرام، طلبات...) باسم المكان. جلب الرقم والعنوان والعروض بالذكاء الاصطناعي شغال بس جوه كلود، ومحتاج سيرفر عشان يشتغل في الـ APK.
- الصفحة نفسها في app/src/main/assets/index.html.
